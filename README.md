### Tokyo Spirit Gesture｜东京灵能手势

Tokyo Spirit Gesture｜东京灵能手势 是一个基于浏览器摄像头的实时手势交互 Demo。
Tokyo Spirit Gesture is a browser-based real-time hand gesture interaction demo.

项目灵感来源于日式都市灵异和超自然动作美学。
The project is inspired by Japanese urban supernatural and action aesthetics.

用户可以通过张手、握拳、双手结印等手势触发御札、火球、灵能子弹等视觉特效。
Users can trigger visual effects such as ofuda, fireballs, and spirit bullets through gestures like open palm, fist, and two-hand seals.

项目结合了 MediaPipe 手部识别、React 前端交互、Canvas 动画和 Web Audio 音效。
The project combines MediaPipe hand tracking, React frontend interaction, Canvas animation, and Web Audio sound effects.

这个 demo 探索了如何通过电脑摄像头和自然手势，让网页交互变得更沉浸、更有游戏感和视觉表现力。
This demo explores how webcam-based natural gestures can make browser interaction more immersive, game-like, and visually expressive.

🔗 项目地址｜Project: https://github.com/ALena006123/Ghost-Gesture-Demo

### 中国城市大富翁 Demo｜China Monopoly Demo

中国城市大富翁 Demo 是一个以中国城市为主题的大富翁网页小游戏。
China Monopoly Demo is a China-themed Monopoly-style web game.

玩家可以掷骰子，在棋盘上移动，购买城市、建造房屋，并根据城市价值支付过路费。
Players can roll dice, move around the board, buy cities, build houses, and pay tolls based on city values.

这个项目帮助我练习了 React 状态管理、游戏逻辑设计和基础网页交互。
This project helped me practice React state management, game logic design, and basic web interaction.

它包含任务管理、每日计划、番茄钟和学习统计等功能，帮助用户更好地安排学习时间。
